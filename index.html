Research, in progress

Nexus Core: a CPU-native language model

Working paper, not yet peer reviewed. I am a co-author.

Most language models need a GPU and use more memory with every token of context. Nexus Core is designed for ordinary CPUs, aimed at edge, offline and privacy-sensitive use. It combines state-space layers, 64 addressable memory slots, linear attention and a 64-token local window, so the history it carries stays a fixed size.

0.90 MiBcarried state, constant as context grows (analytical)
247.6 → 189.2WikiText-2 perplexity, 5k to 20k steps, trained on a laptop CPU
3.97×smaller weights with INT8 and almost no quality loss

The paper also reports its limits: about 6.7 tokens per second today, with kernel optimization as the next step.
